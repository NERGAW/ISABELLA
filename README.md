# I.S.A.B.E.L.L.A.

**Intelligent System for Adaptive Behavior, Environment, Learning, Logic and Assistance**

ISABELLA é uma plataforma pessoal modular de inteligência artificial, local-first, desenvolvida para integrar futuramente:

- inteligência local;
- voz;
- automação do computador;
- memória;
- visão;
- dispositivos;
- interfaces distribuídas.

## Execução

```powershell
python main.py
```

Esta primeira fase contém apenas a fundação do núcleo da aplicação.
